# MaiZI Motion 品牌片

## 一、观众拿到什么

一条能对外发、一眼认得出是 MaiZI Motion 的成片，不是草稿或占位。看的人知道这片子是谁做的。换成别的作品、别的主题，它仍然是这个牌子，而不是一套通用模板换了个名字。片子要在 Studio 里能继续改。

## 二、少了它就不算

品牌归属是真的：牌子的名字、署名的位置、片子说话的方式，属于 MaiZI Motion 和它这次的素材。**如果只把品牌名换成另一个牌子、这条片照样成立，那就是没做完。**

## 三、必须为真

每条都要能查，交付时逐条报结果。

- 全片品牌名逐字写成 `MaiZI Motion`，分成 `MaiZI` 与 `Motion` 两段，两段着色不同（`MaiZI` 白、`Motion` 紫）；不出现 MotionGit、motiongit.com、MOTIONGIT 或任何旧名衍生。`.motion` 是文件格式名，RECIPE / SECTION / EDITOR 是结构术语，GitHub Copilot / Cursor 是第三方工具名，一律不动。
- 品牌署名在成片画面里真实可见，能被截帧读到；只写在文件名、注释或导出设置里不算。同一条片只用一处署名，不重复堆。
- 内容只来自本次给的素材与本次文案，不自动沿用上一次的人物、作品或词句。
- 品牌名、文案与时间点在 Studio 里可编辑，不是烧进一张位图里改不动。
- 交付时报数：时长、切点数、署名出现的秒、`openfilm look` 的告警数与处置结果。

## 四、你手上有什么

OpenFilm 给的：`npx openfilm get` 取素材、`openfilm look` 看片与响度、同一时刻 t 必须画出同一帧的确定性契约、页面本身不发声、片段用 `#t=起,止` 原地裁切不重编码、Studio 里 WebVTT 字幕，以及内置素材库与 14 个成片模板。

这台机器特有的：已连的百炼 provider，6 个 TTS 模型、49 个音色（中文与方言为主），可用 `--instruction` 指定方言语气；`wan2.2-t2i-flash` 生图。`F:\Remotion视频风格库` 与 `_本地模板库` 能出 MP4 镜头，放进 `assets/` 当片段；不做 AI 生视频。其余能出画面的工具照常用，生成的片段连同它的脚本一起进 `assets/`。下载大文件前先问一声。

## 五、跟业主怎么配合

开工要：这次的素材、要不要旁白与用哪个音色、署名那句话（可省）。缺哪样就自己定，不要停下来问，在交付里写明白你定了什么。

做完用几句话讲清：做了什么、为什么这么署名、上面的数字，以及哪些是业主自己的东西还能让片子更好。别报「已按规范完成」，报事实。
